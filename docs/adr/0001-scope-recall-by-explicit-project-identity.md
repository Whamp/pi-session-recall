# Scope recall by explicit project identity before ranking

Conversation Recall will make project scope the default only after Git repositories, non-Git origins, configured lineage, and bounded quality evidence are available together. The Git tracer bullet keeps global scope as a transitional default so evidence outside Git is not silently excluded during rollout.

Project scope admits candidates by exact project identity inside dense, lexical, and identifier retrieval before each channel limit. Canonical Git origins join equivalent clones; a repository's real shared Git directory joins its worktrees when no usable origin exists. Ranking, deduplication, reranking, and context expansion run unchanged on the admitted candidates.

We rejected path-name similarity, content inference, automatic fallback, mixed scopes, and document path-reference machinery. Those alternatives blur the stated boundary or add unmeasured admission rules. Global search remains the explicit escape hatch.
