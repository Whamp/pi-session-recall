# Incremental Ingestion Transition Table

**Prototype finding, not a production specification.**

The source JSONL and Pi lifecycle events remain authoritative. Markers wake the worker or preserve facts that JSONL does not contain. Recall eligibility only grows unless the user confirms source deletion.

## Concurrent runtimes

Each marker carries a random runtime instance ID and monotonic sequence. The projection keeps the latest processed sequence per runtime, but it never tries to choose one globally authoritative active leaf. Branch and compaction eligibility is a monotonic union of every observed context exit.

## Deletion recommendation

An explicit deletion should eventually remove recall evidence because evidence without its source no longer satisfies source-backed recall. A missing path is only a suspicion: confirm it on a later sweep, ensure the session root itself is healthy, and refuse any automatic deletion batch that looks like broad storage loss.

## Backlog recommendation

Search always uses the last durable generation. It warns only when eligible work has failed or the oldest eligible marker exceeds the measured service objective. Ordinary active-tail markers and brief write-window contention do not produce freshness warnings.
